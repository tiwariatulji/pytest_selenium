**pytest और Selenium का पूरा फोल्डर स्ट्रक्चर बनाने की स्टेप-बाई-स्टेप गाइड (Windows के लिए):**

---

### **स्टेप 1: फोल्डर स्ट्रक्चर बनाएं**  
CMD में नीचे दिए कमांड्स चलाएँ:  
```cmd
mkdir pytest-selenium-project  # प्रोजेक्ट का मुख्य फोल्डर
cd pytest-selenium-project     # फोल्डर के अंदर जाएँ
mkdir tests                    # टेस्ट फाइल्स के लिए
mkdir pages                    # पेज ऑब्जेक्ट्स के लिए
mkdir utilities                # ब्राउज़र सेटअप जैसी यूटिलिटीज
mkdir reports                  # HTML रिपोर्ट्स के लिए
mkdir screenshots              # स्क्रीनशॉट्स सेव करने के लिए
```

---

### **स्टेप 2: जरूरी फाइल्स बनाएं**  
CMD में ये कमांड्स चलाएँ:  
```cmd
type nul > conftest.py                # pytest कॉन्फ़िगरेशन
type nul > pytest.ini                 # pytest सेटिंग्स
type nul > requirements.txt           # डिपेंडेंसी लिस्ट
type nul > tests/test_example.py      # टेस्ट केस उदाहरण
type nul > pages/base_page.py         # बेस पेज क्लास
type nul > pages/home_page.py         # होम पेज क्लास
type nul > utilities/browser.py       # ब्राउज़र मैनेजमेंट
```

---

### **स्टेप 3: वर्चुअल एनवायरनमेंट सेटअप करें**  
CMD में:  
```cmd
python -m venv venv       # वर्चुअल एनवायरनमेंट बनाएं
venv\Scripts\activate     # एनवायरनमेंट एक्टिवेट करें
```

---

### **स्टेप 4: लाइब्रेरीज इंस्टॉल करें**  
CMD में:  
```cmd
pip install pytest selenium pytest-html webdriver-manager
```

---

### **स्टेप 5: फाइल्स को कॉन्फ़िगर करें**  

1. **`requirements.txt`** (डिपेंडेंसी लिस्ट):  
   ```txt
   pytest
   selenium
   pytest-html
   webdriver-manager
   ```

2. **`pytest.ini`** (pytest कॉन्फ़िगरेशन):  
   ```ini
   [pytest]
   addopts = --html=reports/report.html --capture=sys -v
   markers =
       smoke: smoke tests
       regression: regression tests
   ```

3. **`utilities/browser.py`** (ब्राउज़र सेटअप):  
   ```python
   from selenium import webdriver
   from webdriver_manager.chrome import ChromeDriverManager
   from webdriver_manager.firefox import GeckoDriverManager

   def setup_browser(browser_name):
       if browser_name.lower() == 'chrome':
           driver = webdriver.Chrome(ChromeDriverManager().install())
       elif browser_name.lower() == 'firefox':
           driver = webdriver.Firefox(executable_path=GeckoDriverManager().install())
       else:
           raise ValueError("Unsupported browser")
       driver.maximize_window()
       return driver
   ```

4. **`tests/test_example.py`** (टेस्ट केस उदाहरण):  
   ```python
   def test_example_search(browser):
       browser.get("https://www.example.com")
       assert "Example Domain" in browser.title
   ```

5. **`conftest.py`** (ब्राउज़र फिक्सचर):  
   ```python
   import pytest
   from utilities.browser import setup_browser

   @pytest.fixture(scope="function")
   def browser():
       driver = setup_browser('chrome')
       yield driver
       driver.quit()
   ```

---

### **स्टेप 6: टेस्ट रन करें**  
CMD में ये कमांड चलाएँ:  
```cmd
pytest tests/  # सभी टेस्ट रन करें
```

---

### **महत्वपूर्ण नोट्स**  
1. **HTML रिपोर्ट**: `reports` फोल्डर में `report.html` जेनरेट होगी।  
2. **ब्राउज़र बदलने के लिए**: `pytest --browser=firefox` (कॉन्फ़िगरेशन में फायरफॉक्स जोड़ें)।  
3. **वर्चुअल एनवायरनमेंट बंद करने के लिए**: `deactivate` कमांड चलाएँ।  

---

### **फोल्डर स्ट्रक्चर का नक्शा**  
```
pytest-selenium-project/
├── tests/
│   ├── test_example.py    # टेस्ट केसेस
│   └── conftest.py        # फिक्सचर
├── pages/
│   ├── base_page.py       # सभी पेज्स की बेस क्लास
│   └── home_page.py       # होमपेज लोकेटर्स और मेथड्स
├── utilities/
│   └── browser.py         # ब्राउज़र मैनेजमेंट
├── reports/               # ऑटो-जेनरेटेड HTML रिपोर्ट्स
├── screenshots/           # टेस्ट फेल होने पर स्क्रीनशॉट
├── pytest.ini             # pytest सेटिंग्स
└── requirements.txt       # डिपेंडेंसी लिस्ट
```

**याद रखें**:  
- Python 3.7 या नया वर्जन इंस्टॉल करें।  
- CMD में सही फोल्डर में कमांड्स चलाएँ।  
- `webdriver-manager` ऑटोमेटिकली Chrome/Firefox ड्राइवर्स को मैनेज करता है।


Key Features Included:

Page Object Model (POM) structure

Browser factory pattern

HTML reporting

Separate directories for reports/screenshots

Configuration file (pytest.ini)

Virtual environment setup

Important Commands:

Activate virtual environment: venv\Scripts\activate

Run all tests: pytest tests/

Run with specific browser: pytest --browser=firefox

Generate HTML report: pytest --html=reports/report.html

Remember to:

Install Python first and add it to PATH

Use Python 3.7 or newer

Keep your drivers updated using webdriver-manager

Activate virtual environment before installing dependencies

Deactivate virtual environment when done with deactivate

**संक्षेप में:**  
इस चैट में Windows पर pytest और Selenium का टेस्टिंग फ्रेमवर्क सेटअप करने का पूरा तरीका बताया गया है। यहाँ मुख्य बिंदु हैं:

1. **फोल्डर स्ट्रक्चर**:  
   - `tests/` (टेस्ट केस), `pages/` (पेज ऑब्जेक्ट्स), `utilities/` (ब्राउज़र सेटअप), `reports/` (HTML रिपोर्ट्स), और `screenshots/` (स्क्रीनशॉट्स) जैसे फोल्डर्स बनाएँ।

2. **जरूरी फाइल्स**:  
   - `conftest.py`, `pytest.ini`, `requirements.txt`, और टेस्ट/पेज क्लासेस की फाइल्स (जैसे `test_example.py`, `base_page.py`) क्रिएट करें।

3. **वर्चुअल एनवायरनमेंट**:  
   - `venv` बनाकर एक्टिवेट करें और लाइब्रेरीज (`pytest`, `selenium`, `pytest-html`, `webdriver-manager`) इंस्टॉल करें।

4. **कॉन्फ़िगरेशन**:  
   - `pytest.ini` में HTML रिपोर्ट जेनरेशन और मार्कर्स सेट करें।
   - `browser.py` में ब्राउज़र ऑटो-मैनेजमेंट (Chrome/Firefox) कोड लिखें।

5. **टेस्ट रन**:  
   - `pytest tests/` कमांड से टेस्ट्स चलाएँ। रिपोर्ट्स `reports/` में सेव होगी।

**महत्वपूर्ण फीचर्स**:  
- **Page Object Model (POM)** डिज़ाइन।  
- ऑटोमेटिक ब्राउज़र ड्राइवर मैनेजमेंट (`webdriver-manager` के साथ)।  
- HTML रिपोर्ट्स और स्क्रीनशॉट्स का प्रबंधन।  
- विभिन्न ब्राउज़र्स (Chrome, Firefox) के लिए सपोर्ट।  

**आवश्यक टूल्स**: Python 3.7+, pytest, Selenium, और Windows CMD का बेसिक ज्ञान।

Here's a step-by-step guide to create a pytest-Selenium folder structure using Windows Command Prompt (CMD):

1. **Create Folder Structure** (Run these commands in CMD):
```cmd
mkdir pytest-selenium-project
cd pytest-selenium-project
mkdir tests
mkdir pages
mkdir utilities
mkdir reports
mkdir screenshots
```

2. **Create Essential Files**:
```cmd
type nul > conftest.py
type nul > pytest.ini
type nul > requirements.txt
type nul > tests/test_example.py
type nul > pages/base_page.py
type nul > pages/home_page.py
type nul > utilities/browser.py
```

Here's the resulting structure:
```
pytest-selenium-project/
├── tests/
│   ├── __init__.py
│   ├── test_example.py
│   └── conftest.py
├── pages/
│   ├── base_page.py
│   └── home_page.py
├── utilities/
│   └── browser.py
├── reports/
├── screenshots/
├── pytest.ini
└── requirements.txt
```

3. **Set Up Virtual Environment**:
```cmd
python -m venv venv
venv\Scripts\activate
```

4. **Install Dependencies**:
```cmd
pip install pytest selenium pytest-html
```

5. **Populate Files**:

*requirements.txt*:
```txt
pytest
selenium
pytest-html
webdriver-manager
```

*pytest.ini*:
```ini
[pytest]
addopts = --html=reports/report.html --capture=sys -v
markers =
    smoke: smoke tests
    regression: regression tests
```

*tests/conftest.py*:
```python
import pytest
from selenium import webdriver
from utilities.browser import setup_browser

@pytest.fixture(scope="function")
def browser():
    driver = setup_browser('chrome')
    yield driver
    driver.quit()
```

*utilities/browser.py*:
```python
from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from webdriver_manager.firefox import GeckoDriverManager

def setup_browser(browser_name):
    if browser_name.lower() == 'chrome':
        driver = webdriver.Chrome(ChromeDriverManager().install())
    elif browser_name.lower() == 'firefox':
        driver = webdriver.Firefox(executable_path=GeckoDriverManager().install())
    else:
        raise ValueError(f"Unsupported browser: {browser_name}")
    driver.maximize_window()
    return driver
```

*tests/test_example.py*:
```python
def test_example_search(browser):
    browser.get("https://www.example.com")
    assert "Example Domain" in browser.title
```

6. **Run Tests**:
```cmd
pytest tests/
```

**Key Features Included**:
- Page Object Model (POM) structure
- Browser factory pattern
- HTML reporting
- Separate directories for reports/screenshots
- Configuration file (pytest.ini)
- Virtual environment setup

**Important Commands**:
- Activate virtual environment: `venv\Scripts\activate`
- Run all tests: `pytest tests/`
- Run with specific browser: `pytest --browser=firefox`
- Generate HTML report: `pytest --html=reports/report.html`

Remember to:
1. Install Python first and add it to PATH
2. Use Python 3.7 or newer
3. Keep your drivers updated using webdriver-manager
4. Activate virtual environment before installing dependencies
5. Deactivate virtual environment when done with `deactivate`
